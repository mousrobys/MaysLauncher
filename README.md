## 🚀 Функционал лаунчера

### 🌟 Уникальные возможности

- **Встроенный бот на базе Mineflayer**
  Мы внедрили технологию, которая позволяет создавать игрового бота прямо из лаунчера. Запустите его на своём локальном мире или подключите к любому серверу — это идеальное решение для автоматических ферм (AFK) без необходимости заводить множество аккаунтов. Всё управление ботом вынесено в удобную панель внутри лаунчера.

- **Загрузка сборок в любых форматах**
  Поддерживаются не только стандартные ZIP-архивы, но и современные MRPACK-файлы. Просто перетащите сборку — и она будет готова к установке.

- **Прямая загрузка модов из CurseForge**
  Скачивайте моды напрямую, без использования прокси и VPN. Встроенный механизм обходит региональные ограничения и работает быстро.

### ⚙️ Стандартные, но важные функции

- **Создание и управление сборками** — добавляйте, удаляйте и редактируйте моды в несколько кликов
- **Гибкие настройки памяти (RAM)** — выделите нужный объем оперативной памяти для стабильной работы даже с тяжелыми модпаками
- **Полная кастомизация интерфейса:**
  - Меняйте фоновые изображения, цвета, иконки и шрифты
  - Настраивайте внешний вид под своё настроение — лаунчер становится вашим
- **Параметры запуска Java** — для продвинутых пользователей доступны тонкие настройки JVM-аргументов

### 📋 Удобство для пользователя

- **Многоязычность** — выберите язык интерфейса: русский, украинский или английский
- **Умный скин-система** — лаунчер автоматически подбирает скин по вашему никнейму в офлайн-режиме
- **Продвинутые логи** — все ошибки и предупреждения разделены по категориям (фильтрам), что упрощает их поиск и анализ
